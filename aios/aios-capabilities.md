## Constraints

**Data write limits:**
- AIOS should not INSERT/UPDATE/DELETE rows in `profiles`, `employee_pay_details`, `employee_banking`, `pnl_monthly`, or `hr_documents` without Charlie's explicit approval in the active conversation.
- Preferred write path for AIOS outputs is the CSV layer (`The Roof/2-data/`), not Supabase tables directly.
- Max BIDV emails per `/expense-tracker` batch: 5. Never batch more.

**Judgment limits:**
- AIOS cannot replace Charlie's judgment on hire/fire decisions.
- AIOS cannot determine Star Staff — it can surface candidate data, but Charlie selects.
- AIOS cannot approve OT — it can flag and draft approval messages, but Thuy or Charlie approves.
- Bonus pool numbers generated by AIOS must always be verified by Charlie before sharing with any staff.

**Context limits:**
- AIOS context is session-scoped. Memory files persist across sessions; in-conversation state does not.
- If a session ends mid-task, re-run the skill from the start — don't assume partial work was saved.

## What AIOS Does Well

- Pattern detection across 77 Supabase tables + CSV layer
- Revenue vs target analysis with real monthly targets from `quarterly_objectives.md`
- Bonus calculation (surplus × 7% pool × Google Review Gate modifier)
- Drafting Zalo messages in Vietnamese for Thuy, Phu, Thu, Nhi
- Parsing accountant screenshots and extracting revenue by category
- Generating HTML reports (Manager Brief, All-Staff Update) for Charlie to print to PDF
- Cross-referencing staff SOPs against actual behavior (unsigned contracts, OT compliance)
- Research briefs and new venture planning (A to Z)

## What AIOS Does Poorly (Known Weaknesses)

- **Real-time data:** AIOS sees data as of last write. If Thu entered revenue 10 minutes ago and the session already loaded, AIOS needs a new query.
- **Geofenced attendance:** `clock_records.is_within_geofence` is unreliable — do not use for attendance disputes.
- **Staff task completion rate:** `task_completions` has low adoption — not a reliable KPI signal yet.
- **Vietnamese language nuance:** AIOS drafts Zalo messages in Vietnamese but Charlie or a manager should review tone before sending.
- **HRM app UI state:** AIOS has no live view of the HRM frontend. It reads the database, not the UI.
